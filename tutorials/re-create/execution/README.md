# AI 执行链路说明

本目录将电商 Agent 改造拆成 5 条可独立执行、逐级验收的开发链路。每份文档都可以直接交给一个 AI 编码会话使用。

## 使用方式

1. 从 `01` 开始，按编号顺序执行。
2. AI 开始工作前必须读取当前链路的全部“必读输入”。
3. AI 只能在当前链路声明的范围内修改代码。
4. AI 完成代码、测试和文档后，运行链路内的验收命令。
5. 将提交摘要、命令结果、遗留风险和下一链路输入写入：

```text
packages/commerce-agent/demo/progress.md
```

6. 只有当前链路满足“完成门槛”后，才继续下一份文档。

## 每次交接必须包含

- 本轮新增或修改的文件；
- 已通过的测试命令及结果；
- 尚未解决的问题；
- 新增的配置项、环境变量或启动方式；
- 下一条链路可直接复用的接口、样例输入和产物路径。
